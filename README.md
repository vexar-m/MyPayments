> **🤖 Важное примечание / Important Note:**  
> **Приложение полностью спроектировано, написано и оптимизировано с помощью ИИ (AI Assistant / Gemini в Android Studio).**

---

## 📱 О приложении / About The App

**«Мои Платежи»** — это современное Android-приложение для удобного учёта регулярных расходов: подписок на онлайн-сервисы, коммунальных платежей (ЖКХ) и установления лимитов на внутриигровые покупки.

Приложение строго придерживается гайдлайнов **Material Design 3 (Material Expressive)** и поддерживает адаптивную динамическую цветовую гамму из обоев смартфона (**Material You**).

---

## ✨ Основные функции / Key Features

- **📊 3 Категории расходов**:
  1. **Подписки**: Популярные сервисы (*Boosty, Telegram Premium, Яндекс Плюс, ChatGPT, Spotify, Kinopoisk, Steam, Discord Nitro, VK Музыка и др.*) + ручной ввод.
  2. **Ежемесячные платежи**: ЖКХ, аренда, мобильная связь (*МТС, Билайн, МегаФон, t2*), интернет.
  3. **Оплаты в играх**: Лимиты расходов в месяц на любимых площадках (*Steam, PlayStation, Xbox, Genshin Impact, Brawl Stars, Roblox, CS2, World of Tanks*).

- **⚠️ Система предупреждений о превышении бюджета**:
  - Установка месячного лимита на подписки (например, 1 000 ₽/мес).
  - Умное окно предупреждения при превышении с возможностью повысить или отключить лимит в 1 клик.

- **🔗 Управление подпиской в 1 клик**:
  - Каждая подписка содержит прямую ссылку на сайт управления.
  - Кнопка **«Управление»** на карточке открывает страницу отмены или продления в браузере.

- **📱 Виджет для рабочего стола (MD3)**:
  - Компактный и стильный виджет для главного экрана смартфона с отображением ближайших 3 подписок к оплате.

- **🔔 Локальные Пуш-уведомления & Отключение экономии энергии**:
  - Напоминания о предстоящей оплате в точное время через `AlarmManager`.
  - Встроенная кнопка для **отключения оптимизации батареи** в настройках.

- **⚙️ Гибкие настройки & Мультиязычность**:
  - Поддержка **Русского** и **Английского** языков.
  - **Светлая**, **Тёмная** и **Системная** темы.
  - Выбор цветовых акцентов (Material You / Пурпурный, Синий, Изумрудный, Коралловый, Золотой).

- **🚀 Оптимизация & Анимации**:
  - Высокая производительность рендеринга на Compose, отсутствие задержек, плавные анимации списка `animateItem()` и переходов `Crossfade`.

## 🛠️ Технологический стек / Tech Stack

- **Язык**: Kotlin 2.2
- **UI Фреймворк**: Jetpack Compose (Material Design 3 / Material Expressive)
- **Архитектура**: MVVM (ViewModel, StateFlow, Coroutines)
- **Виджет**: Android RemoteViews AppWidget (MD3)
- **Уведомления**: AlarmManager, NotificationCompat, PostNotifications
- **Минимальная версия Android**: Android 9.0 (API 28+)
- **Целевая версия Android**: Android 15 (API 37)

## 🚀 Инструкция по сборке и запуску / How to Build & Run

### Требования:
- **Android Studio**: Ladybug / 2024.2.1+
- **JDK**: 17 или 21
- **Android SDK**: API 35/37

### Сборка через Gradle CLI:

```bash
# Сборка Debug APK
./gradlew assembleDebug

# Установка на подключенный смартфон/эмулятор
./gradlew installDebug

# Запуск приложения на устройстве
adb shell am start -n com.devdd.mypayments/.MainActivity
```

Готовый файл APK будет находиться по пути:
`app/build/outputs/apk/debug/app-debug.apk`
